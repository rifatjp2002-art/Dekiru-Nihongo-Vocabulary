## 📖 Overview (পরিচিতি)

**Dekiru A1-B1** হলো জাপানি ভাষা শিক্ষার্থীদের জন্য তৈরি একটি বিশ্বমানের, আধুনিক ও সম্পূর্ণাঙ্গ প্রোগ্রেসিভ ওয়েব অ্যাপ্লিকেশন (PWA)। বিখ্যাত **できる日本語 (Dekiru Nihongo)** বই সিরিজের প্রাথমিক (初級 - Book 1, A1-A2) এবং প্রাক-মধ্যম (初中級 - Book 2, A2-B1) উভয় খণ্ডের মোট **৩০টি লেসনের ২,০৭৪টিরও বেশি শব্দ** এখানে অত্যন্ত যত্নসহকারে ও নিখুঁতভাবে সন্নিবেশিত করা হয়েছে।

প্রতিটি শব্দের সাথে রয়েছে সঠিক কাঞ্জি, ফুরিগানা (হিরাগানা/কাতাকানা উচ্চারণ), বাংলা ও ইংরেজি অর্থ, জাপানি বাক্য ও তার বঙ্গানুবাদ এবং মানুষের মতো স্বাভাবিক জাপানি অডিও উচ্চারণ (Native Browser TTS)। এটি সম্পূর্ণ অফলাইন-বান্ধব এবং মোবাইল অ্যাপ হিসেবে সরাসরি যেকোনো অ্যান্ড্রয়েড, আইফোন বা কম্পিউটারে ইনস্টল করে ব্যবহার করা যায়।

## ✨ Features (মূল বৈশিষ্ট্যসমূহ)

### 📱 ১. ইনস্টলযোগ্য মোবাইল অ্যাপ (Progressive Web App - PWA)
- **ওয়ান-ক্লিক ইনস্টল:** ব্রাউজার ওপেন না করেই মোবাইল বা কম্পিউটারে নেটিভ অ্যাপের মতো ইনস্টল করে নিন।
- **অফলাইন অ্যাক্সেস:** একবার লোড করার পর সম্পূর্ণ অ্যাপটি ইন্টারনেট কানেকশন ছাড়াও ফুল স্পিডে সচল থাকে।
- **আইওএস ইনস্টলেশন গাইড:** আইফোন/আইপ্যাড ব্যবহারকারীদের জন্য রয়েছে সহজ ধাপে ধাপে ইনস্টলেশনের চমৎকার ইউজার ইন্টারফেস।

### 📚 ২. সম্পূর্ণ শব্দভাণ্ডার ও দ্বি-মুখী বই (Dual Book Mode)
- **বই ১ (できる日本語 初級 - Shokyu A1/A2):** ১৫টি লেসন • ১,১১৫টি শব্দ।
- **বই ২ (できる日本語 初中級 - Shokyuchu B1):** ১৫টি লেসন • ৯৫৯টি শব্দ।
- যেকোনো সময় সিঙ্গেল ক্লিকে সম্পূর্ণ ডেটাসেট পরিবর্তনের ইনস্ট্যান্ট সুবিধা।

### 🎴 ৩. ইন্টারেক্টিভ ফ্ল্যাশকার্ড ও অডিও উচ্চারণ (Flashcards with Audio)
- মনমুগ্ধকর থ্রিডি স্পিনিং অ্যানিমেশনসহ দুই পাশের ফ্ল্যাশকার্ড (জাপানি শব্দ ↔ বাংলা/ইংরেজি অর্থ ও বাস্তব উদাহরণ)।
- **জাপানি অডিও প্রোনাউন্সিয়েশন (Native TTS Engine):** বোতামে চাপলেই জাপানি ভাষার সঠিক এবং নির্ভুল উচ্চারণ শোনার ব্যবস্থা।
- প্রিয় শব্দগুলোকে বুকমার্ক (Save) করে আলাদা তালিকায় সংরক্ষণ করে রিভিশন করার সুবিধা।

### 📝 ৪. স্মার্ট কুইজ ও পারফর্ম্যান্স ট্র্যাকিং (Smart Quiz Engine)
- **দ্বিমুখী কুইজ:** জাপানি থেকে বাংলা অথবা বাংলা থেকে জাপানি শব্দ বেছে নেওয়ার সুযোগ।
- ভুল উত্তরের সাথে সাথে সঠিক ব্যাখ্যা ও হাইলাইট।
- বিস্তারিত কুইজ হিস্ট্রি ও পারফর্ম্যান্স অ্যানালিটিক্স।

### ⏰ ৫. প্রতি ঘণ্টার শব্দ (Word of the Hour)
- প্রতিদিন একই শব্দ মুখস্থ করার একঘেয়েমি কাটাতে প্রতি ঘণ্টার শুরুতে হোম স্ক্রিনে সম্পূর্ণ নতুন একটি শব্দ প্রদর্শিত হয়।
- যেকোনো সময় নতুন শব্দ পরিবর্তন করার জন্য রয়েছে **"পরবর্তী শব্দ 🔄"** বাটন।

### 📊 ৬. প্রোগ্রেস ও স্টাডি ট্র্যাকার (Comprehensive Dashboard)
- রিয়েল-টাইম রেসপনসিভ বার চার্ট এবং পার্সেন্টেজ প্রোগ্রেস বার।
- **স্বয়ংসক্রিয় স্টাডি টাইমার:** প্রতিদিন কত মিনিট মন দিয়ে জাপানি ভাষা চর্চা করেছেন তার নিখুঁত লাইভ কাউন্টার।
- **ডেইলি স্ট্রিক কাউন্টার:** পড়াশোনার ধারাবাহিকতা ধরে রাখতে সাহায্য করে।

### ☁️ ৭. নিরাপদ ফায়ারবেস ক্লাউড ব্যাকআপ ও সিঙ্ক (Google Login Sync)
- **অফলাইন-ফার্স্ট:** ব্রাউজারের অত্যন্ত দ্রুতগতির `IndexedDB` ব্যবহার করায় ইন্টারনেট সংযোগ চলে গেলেও কোনো ডেটা হারাবে না।
- **গুগল ক্লাউড সিঙ্ক:** গুগল দিয়ে লগইন করে যেকোনো নতুন ফোন বা ব্রাউজার থেকে নিজের শেখার প্রোগ্রেস এবং বুকমার্ক করা শব্দ পুনরুদ্ধার করুন।
- ইন-অ্যাপ সেটিংস থেকে এক ক্লিকে সম্পূর্ণ ডেটা রিসেট করার নিরাপদ অপশন।

## 🛠️ Tech Stack (ব্যবহৃত প্রযুক্তি)

- **Frontend Core:** React 19, TypeScript
- **Styling:** Tailwind CSS v4 (মডার্ন পারফর্ম্যান্স ও ডার্ক নিয়ন থিম)
- **State & Sync:** Zustand, IndexedDB API
- **Cloud Database:** Firebase Firestore & Google Auth (নিরাপদ ব্যবহারকারী প্রমাণীকরণ)
- **Build Engine & PWA Tools:** Vite, `vite-plugin-pwa` (অটোমেটিক সার্ভিস ওয়ার্কার ও প্রিক্যাচিং জেনারেটর)

## 📲 How to Install as an App (যেভাবে অ্যাপ হিসেবে ইন্সটল করবেন)

### 🤖 Android & Chrome (অ্যান্ড্রয়েড/পিসি)
1. আপনার ফোনে বা কম্পিউটারে ক্রোম ব্রাউজার ব্যবহার করে সাইটটিতে প্রবেশ করুন।
2. নেভিগেশন বারের ওপরে থাকা **"সেভ করুন (Install App)"** বাটনে চাপ দিন।
3. পপআপে **Install** সিলেক্ট করুন। ব্যাস, অ্যাপটি আপনার মোবাইল স্ক্রিনে চলে আসবে!

### 🍏 iOS (iPhone & iPad)
1. **Safari** ব্রাউজার ব্যবহার করে সাইটটি ওপেন করুন।
2. নিচের টুলবারের **Share (শেয়ার)** আইকনে ট্যাপ করুন।
3. একটু নিচে স্ক্রোল করে **Add to Home Screen** অপশনটিতে ক্লিক করুন। 
4. নাম **Dekiru A1-B1** রেখে **Add**-এ চাপ দিন।

## 🚀 Getting Started for Developers (ডেভেলপারদের জন্য গাইড)

### ১. প্রয়োজনীয় উপাদান:
- [Node.js](https://nodejs.org/) (সংস্করণ ১৮ বা তার বেশি)
- `npm`

### ২. লোকাল সেটআপ ও রান:

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/rifatjp2002-art/Dekiru-Nihongo-Vocabulary.git

# ২. প্রজেক্ট ডিরেক্টরিতে প্রবেশ করুন
cd Dekiru-Nihongo-Vocabulary

# ৩. প্যাকেজসমূহ ইন্সটল করুন
npm install

# ৪. সার্ভিস ওয়ার্কার ও আইকন জেনারেট করুন
npm run build

# ৫. লোকাল সার্ভারে ডেভেলপমেন্ট রান করুন
npm run dev
```

ব্রাউজারে `http://localhost:3000` এ আপনার লোকাল কপি দেখতে পাবেন।
