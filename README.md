## 📖 Overview (পরিচিতি)

**Dekiru Nihongo Vocabulary Master** হলো জাপানি ভাষা শিক্ষার্থীদের জন্য তৈরি একটি আধুনিক ও পূর্ণাঙ্গ ওয়েব অ্যাপ্লিকেশন। বিখ্যাত **できる日本語 (Dekiru Nihongo)** বই সিরিজের প্রাথমিক (初級 - Book 1) এবং প্রাক-মধ্যম (初中級 - Book 2) উভয় খণ্ডের মোট **৩০টি লেসনের ২,০৭৪টিরও বেশি শব্দ** এখানে অত্যন্ত যত্নসহকারে সন্নিবেশিত করা হয়েছে।

প্রতিটি শব্দের সাথে রয়েছে সঠিক কাঞ্জি, ফুরিগানা (হিরাগানা/কাতাকানা উচ্চারণ), বাংলা ও ইংরেজি অর্থ, জাপানি বাক্য ও তার বঙ্গানুবাদ এবং মানুষের মতো স্বাভাবিক জাপানি অডিও উচ্চারণ (Text-to-Speech)।

## ✨ Features (মূল বৈশিষ্ট্যসমূহ)

### 📚 ১. সম্পূর্ণ শব্দভাণ্ডার (Complete 2,074+ Words)
- **বই ১ (できる日本語 初級 - Shokyu):** ১৫টি লেসন • ১,১১৫টি শব্দ
- **বই ২ (できる日本語 初中級 - Shokyuchu):** ১৫টি লেসন • ৯৫৯টি শব্দ
- সহজ এক-ক্লিক বুক সুইচার দিয়ে যেকোনো সময় বই পরিবর্তন করার সুবিধা।

### 🎴 ২. ইন্টারেক্টিভ ফ্ল্যাশকার্ড (Flashcards with Audio)
- ফ্লিপ অ্যানিমেশনসহ দুই পাশের ফ্ল্যাশকার্ড (জাপানি শব্দ ↔ বাংলা/ইংরেজি অর্থ ও উদাহরণ)।
- **জাপানি অডিও প্রোনাউন্সিয়েশন (TTS):** বোতামে চাপলেই নির্ভুল জাপানি উচ্চারণ শোনার সুবিধা।
- বুকমার্ক (Save) এবং জানা/না-জানা শব্দ আলাদা করে পড়ার সুযোগ।

### 📝 ৩. স্মার্ট কুইজ সিস্টেম (Quiz & Score Tracking)
- **দ্বিমুখী কুইজ:** জাপানি থেকে বাংলা অথবা বাংলা থেকে জাপানি নির্বাচন।
- তাৎক্ষণিক সঠিক/ভুল উত্তর শনাক্তকরণ ও ব্যাখ্যা।
- কুইজ হিস্ট্রি এবং পারফর্ম্যান্স অ্যানালিটিক্স।

### ⏰ ৪. প্রতি ঘণ্টায় বিশেষ শব্দ (Hourly Word of the Hour)
- দিনভর এক শব্দে আটকে না থেকে বৈশ্বিক ঘড়ি অনুযায়ী **প্রতি ঘণ্টায় স্বয়ংক্রিয়ভাবে নতুন শব্দ** পরিবর্তিত হয়।
- ইনস্ট্যান্ট নতুন শব্দ পড়ার জন্য **"পরবর্তী শব্দ 🔄"** বাটন।

### 📊 ৫. শেখার অগ্রগতি ও স্টাডি টাইমার (Study Analytics)
- রিয়েল-টাইম বার চার্ট ও পার্সেন্টেজ প্রোগ্রেস বার।
- স্বয়ংক্রিয় স্টাডি টাইমার (কত মিনিট/ঘণ্টা পড়া হয়েছে তার সঠিক হিসাব)।
- ডেইলি স্ট্রিক ট্র্যাকার (শেখার নিয়মিততা বজায় রাখার জন্য)।

### ☁️ ৬. নিরাপদ লোকাল ডাটাবেজ ও ক্লাউড সিঙ্ক
- **অফলাইন-ফার্স্ট:** ব্রাউজারের `IndexedDB` ব্যবহার করায় ইন্টারনেট ছাড়াও অ্যাপ দ্রুত কাজ করে।
- **Google Cloud Backup:** গুগল অ্যাকাউন্ট দিয়ে লগইন করে যেকোনো ডিভাইস থেকে নিজের প্রোগ্রেস সিঙ্ক করার সুবিধা।
- **১০০% নিরাপদ রিসেট বাটন:** এক ক্লিকে ইন-অ্যাপ কনফার্মেশনসহ পুরো ডেটা পরিষ্কার করার অপশন।

### 📱 ৭. মোবাইল ও ডার্ক মোড অপ্টিমাইজড
- আধুনিক জাপানি সাকুরা ও ডার্ক নান্দনিক থিম।
- যেকোনো স্মার্টফোন, ট্যাবলেট এবং কম্পিউটারের জন্য ফুললি রেসপনসিভ।

## 🚀 Getting Started (কীভাবে রান করবেন)

### প্রয়োজনীয় পূর্বশর্ত:
- [Node.js](https://nodejs.org/) (সংস্করণ ১৮ বা তার বেশি)
- `npm` অথবা `yarn`

### ইনস্টলেশন ও লোকাল সার্ভার রান:

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/rifatjp2002-art/Dekiru-Nihongo-Vocabulary.git

# ২. প্রজেক্ট ফোল্ডারে প্রবেশ করুন
cd Dekiru-Nihongo-Vocabulary

# ৩. প্যাকেজসমূহ ইনস্টল করুন
npm install

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

সার্ভার চালু হলে ব্রাউজারে `http://localhost:3000` এ অ্যাপটি ওপেন করুন।

## 📦 Production Build (প্রোডাকশন বিল্ড)

```bash
# প্রোডাকশনের জন্য বিল্ড তৈরি করতে
```
